## 使用教學：

### 請確保你有把 [通用前置作業四步驟](https://fishboss.gitbook.io/tutorial) 做完(尤其安全開機和TPM一定要關)

### 第一步：請先下載 STEAM平台[(點我下載steam)](https://store.steampowered.com/about/)

<div align="left"><figure><img src="../../.gitbook/assets/image (206).png" alt="" width="368"><figcaption></figcaption></figure></div>

### 下載完請安裝並且登入帳號，之後放在背景不要關

<div align="left" data-full-width="false"><figure><img src="../../.gitbook/assets/image (369).png" alt=""><figcaption></figcaption></figure></div>

### 第二步：解壓縮輔助，以管理員身份運行輔助程式。主要載點：[點我前往](https://mega.nz/folder/kfcwAIgZ#Mw0Dr0Pmlh5mhIptkwrbTw)

<figure><img src="../../.gitbook/assets/image (371).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/image (372).png" alt=""><figcaption></figcaption></figure>

### 第三步：會跳出下方提示，點確定可直接跳過。 (下方提示內容翻譯: 請把輔助檔案放在USB裡面運行，注入輔助之後即可拔除USB)

<figure><img src="../../.gitbook/assets/image (374).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
### 魚老闆：雖然KA說要在USB運行程式，

### 但其實直接在電腦執行也是沒問題的(我自己是沒有放在USB內開啟)，

### 穩定度一樣在，但如果<mark style="background-color:green;">追求最穩定</mark>的使用者，

### 那我會<mark style="background-color:green;">建議把檔案放在USB裡面使用</mark>。
{% endhint %}

### 第四步：輸入卡號 > 點下Login來登入(激活)輔助，之後點 確定

<figure><img src="../../.gitbook/assets/image (375).png" alt=""><figcaption></figcaption></figure>

### 第五步：點Start啟動輔助

{% hint style="success" %}
### 這邊會顯示

#### 你購買的類型(Game):

#### 產品目前狀態(Status): undetected(未被檢測)

#### 卡密到期日(key expiration)
{% endhint %}

<figure><img src="../../.gitbook/assets/image (207).png" alt=""><figcaption></figcaption></figure>

### 第六步：等待輔助加載

<figure><img src="../../.gitbook/assets/image (378).png" alt=""><figcaption></figcaption></figure>

### 第七步：加載成功會跳出Successful，一樣點確定，然後就開遊戲 (如果前面是有插著usb的，這時候就可以拔掉了)

### <mark style="color:red;">(遊戲關閉之後 如果想再次使用輔助 請先重新啟動電腦)</mark>

<figure><img src="../../.gitbook/assets/image (379).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
<mark style="color:green;background-color:yellow;">菜單開啟鍵</mark>：INS鍵或是旁邊的HOME鍵\
![](<../../.gitbook/assets/image (380).png>)
--------------------------------------------
{% endhint %}
