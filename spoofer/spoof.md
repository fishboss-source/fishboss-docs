# 遠端解機 | 前置作業

## 第一步：解機前置

### APEX + EAC/BE遊戲 : 刷BIOS系統+重灌(<mark style="background-color:red;">必須做</mark>) VALORANT特戰英豪 : 刷BIOS系統+重灌(<mark style="background-color:red;">必須做</mark>，不做解100%失敗)

{% hint style="info" %}
## 重灌建議灌Win10 專業版(21H2或22H2)
{% endhint %}

### 重灌教學：[https://ofeyhong.pixnet.net/blog/post/192436501](https://ofeyhong.pixnet.net/blog/post/192436501)

<figure><img src="../.gitbook/assets/image (318).png" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
### ！！請務必把所有磁碟機都刪掉並且格式化，沒格式化等於沒重灌！！
{% endhint %}

### BIOS刷新教學：看下方影片

{% hint style="info" %}
### <mark style="color:green;background-color:yellow;">刷BIOS(一次下載好最舊版+最新版驅動)</mark> (在BIOS中<mark style="background-color:red;">先刷最舊再刷最新</mark>，中途不要進系統/電腦登入畫面) 建議先刷最舊版本BIOS>再刷最新版本BIOS 中間請注意，<mark style="background-color:red;">千萬不要進入系統</mark>，<mark style="background-color:red;">否則失敗</mark>。 刷兩次可以高度確保，90%以上成功過機器解鎖
{% endhint %}
