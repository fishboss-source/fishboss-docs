## 二、安裝輔助

### 0. 設定USB(極度建議)

> 沒有USB隨身碟的 可以去超商買一個便宜的 不用多好

1.  電腦插入USB隨身碟，並格式化至 \[FAT32格式]

    <figure><img src="../.gitbook/assets/image (255).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
### **注意** 此步驟非常重要，不是 \[FAT32格式] 必出問題
{% endhint %}

### 1. 下載輔助

1.  點擊 [下載點我](https://mega.nz/folder/KuACASwK#NW3Cpb3Xm7g2vtwwByazoQ) 進行下載。 (解壓縮密碼： `CHUD` )

    <div align="left"><figure><img src="../.gitbook/assets/image (198).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="success" %}
注意

### 請記得先裝必裝驅動 然後才去開啟動器
{% endhint %}



2.  檔案下載下來後請先解壓縮 (解壓縮密碼： `CHUD` )，並且把 輔助檔案 = 亂碼.hta 放置於剛剛的USB隨身碟內

    <div align="left"><figure><img src="../.gitbook/assets/image (257).png" alt=""><figcaption></figcaption></figure></div>

### 2. 打開輔助 (雙擊開啟，不用右鍵管理員)

> 到USB隨身碟裡面找到檔案(亂碼.hta) 直接打開他

### 3. 第一次使用輔助會要你重啟

> 按下 ok按鈕 自動重啟電腦

<div align="left"><figure><img src="../.gitbook/assets/image (258).png" alt=""><figcaption></figcaption></figure></div>

### 4. 重啟電腦後，搜尋 `winver` ，並以管理員身分運行

> winver打開之後放著別關

<div align="left"><figure><img src="../.gitbook/assets/image (259).png" alt=""><figcaption></figcaption></figure></div>

### 5. 再次雙擊打開輔助檔案(亂碼.hta)

<div align="left"><figure><img src="../.gitbook/assets/image (260).png" alt=""><figcaption></figcaption></figure></div>

1. 輸入帳號密碼 (購買輔助後會發)

> 只能手動輸入，請務必注意大小寫\
> 數字輸入 必須使用鍵盤上排數字鍵 九宮格數字鍵沒用

<div align="left"><figure><img src="../.gitbook/assets/image (261).png" alt=""><figcaption></figcaption></figure></div>

2.  選擇輔助 > 按\[Load按鈕]

    <div align="left"><figure><img src="../.gitbook/assets/image (262).png" alt=""><figcaption></figcaption></figure></div>
3.  輔助加載成功後，介面會自動消失

    <div align="left"><figure><img src="../.gitbook/assets/image (264).png" alt=""><figcaption></figcaption></figure></div>

### 6. 工具列右下 > 退出USB > 拔除USB隨身碟

<div align="left"><figure><img src="../.gitbook/assets/image (265).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="warning" %}
### **注意** USB務必退出並拔除，插在電腦上開遊戲會有封號風險
{% endhint %}

### 7. 確認USB隨身碟拔除後，即可開啟遊戲

***

### <mark style="background-color:green;">輔助使用</mark>

1. 使用過程需持續開著 winver
2. 遊戲設定：視窗化 / 無邊框
3. 自瞄功能：距離太遠不會作用(不是自瞄無效)
4. 菜單顯示：\[INS]簡易菜單顯示 | \[DEL] 主要菜單顯示

***

## 三、疑難排解

### 輔助無法啟動、錯誤碼C000 / C005 / C006、無效、閃退

* 請先往上再看一次輔助教學，是否每個步驟都有做
* 請確保你有把 [通用前置作業四步驟](https://fishboss.gitbook.io/tutorial) 做完
* 查看[疑難排解](https://fishboss.gitbook.io/tutorial/instruction/faq)
* 請確認winver是否有用管理員身分開啟，並且沒有被關閉
