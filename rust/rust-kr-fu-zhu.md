## 一、前置作業

### 請確保你有把 [通用前置作業四步驟](https://fishboss.gitbook.io/tutorial) 做完

### 做完後先重開機，然後繼續往下看

## 二、安裝輔助

### 1.程序載點(點我前往)

點擊後等待約5秒將自動下載

### 2.下載完成後右鍵輔助(.exe) 並以系統管理員身分執行

<div align="left"><figure><img src="../.gitbook/assets/image (168).png" alt=""><figcaption></figcaption></figure></div>



### 3.初次使用的話請先註冊帳號然後登入。後續使用直接登入帳密即可

(每台電腦<mark style="color:red;">只能註冊一隻KR帳號</mark><mark style="color:$info;">，</mark>不可再次註冊) (若卡號過期，再用同個KR帳號續卡即可)

<div align="left"><figure><img src="../.gitbook/assets/image (169).png" alt=""><figcaption></figcaption></figure></div>



### 4.等輔助檢查環境(需先移除特戰反作弊/其他防毒軟體)&#x20;

檢查完成後會自動進入輔助菜單

此步驟可能會自動重啟電腦，如果觸發自動重啟電腦，重開電腦之後須<mark style="color:red;">手動打開輔助</mark>

<div align="left"><figure><img src="../.gitbook/assets/image (170).png" alt=""><figcaption></figcaption></figure></div>

### 5.找到你買的遊戲輔助，點擊播放鍵選擇操作

輔助選擇:RUST    EFT選擇:EFT-Full

<div align="left"><figure><img src="../.gitbook/assets/image (171).png" alt=""><figcaption></figcaption></figure></div>

接著選擇是否使用機碼偽裝 - 輸入卡號 - 點擊開始即可使用

使用卡號之後請點擊左側菜單灰階空白處 - 再次點選操作 - 點開始

<div align="left"><figure><img src="../.gitbook/assets/image (172).png" alt=""><figcaption></figcaption></figure></div>

顯示成功後請直接打開遊戲

<div align="left"><figure><img src="../.gitbook/assets/image (173).png" alt=""><figcaption></figcaption></figure></div>

### 6.進入遊戲大廳後按下F5鍵啟動輔助

菜單熱鍵:INS鍵(顯示/隱藏菜單)

遊戲設置必須為<mark style="color:red;">視窗化/無邊框</mark>，否則沒效果

<div align="left"><figure><img src="../.gitbook/assets/image (174).png" alt=""><figcaption></figcaption></figure></div>

切換為中文請到Settings(設置) - Chinese(中文)

<div align="left"><figure><img src="../.gitbook/assets/image (175).png" alt=""><figcaption></figcaption></figure></div>

如果沒找到切換的地方，可參考下方翻譯圖

### 中文翻譯圖(還沒來)

## 三、疑難排解

### 中文菜單顯示亂碼([點我解決](../instruction/faq/changelanguage.md))

### 遊戲啟動判讀問題

先重啟電腦並<mark style="color:red;">開遊戲2次+設置無邊框</mark>，然後關遊戲。

&#x20;接著再管理員啟動輔，然後再次啟動遊戲測試。

### 提示找不到卡密(Couldn't find this key)

(提示出現=你已加值成功了，不需再加值)

重啟電腦 -> 管理員重開輔助-> 登入KR會員

別動直到他跑出輔助選項為止(轉圈轉完)

<mark style="color:red;">沒轉完圈圈啥都別動</mark>-> 跑出輔助選項-> 問題解決
