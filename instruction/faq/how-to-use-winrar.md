# WinRAR 安裝與解壓縮教學

本指南將帶您快速完成 WinRAR 的下載、安裝，並掌握最常見的「解壓縮」與「壓縮」檔案操作。

## 1. WinRAR 下載與安裝步驟

{% stepper %}
{% step %}
### 步驟一：下載官方安裝檔

1. 前往 [WinRAR 台灣官方網站](https://rar.tw/download.php?file=winrar-x64-723tc.exe)。
2. 根據您的作業系統版本選擇下載：
   * 現代電腦請優先選擇：**WinRAR 64-bit (64位元) 中文版**。
{% endstep %}

{% step %}
### 步驟二：執行安裝

1. 雙擊打開下載好的 `.exe` 安裝檔案。
2. 點擊 **「安裝 (Install)」**。
3. 在關聯檔案設定視窗（預設已勾選 RAR、ZIP 等），直接點擊 **「確定 (OK)」**。
4. 點擊 **「完成 (Done)」**，即完成安裝。
{% endstep %}
{% endstepper %}

## 2. 如何解壓縮檔案（收件/下載檔案後）

當您下載了 `.rar` 或 `.zip` 檔案，請使用以下方法解壓：

### 方法 A：解壓縮到獨立資料夾（推薦）

* **操作：** 在壓縮檔上點選滑鼠右鍵 ➔ 選擇 **「解壓縮到 "檔案名稱\\" (Extract to...)」**。
* **優點：** 檔案會自動集中在一個同名資料夾內，桌面或資料夾不會被散落的檔案弄髒。

### 方法 B：解壓縮至當前位置

* **操作：** 在壓縮檔上點選滑鼠右鍵 ➔ 選擇 **「解壓縮至此 (Extract Here)」**。
* **注意：** 如果壓縮檔內檔案很多且沒有資料夾包裹，會直接散落在當前目錄。

{% hint style="info" %}
如果檔案設有密碼，解壓縮時會跳出輸入框，請輸入賣家提供的正確密碼即可。
{% endhint %}

## 3. 如何壓縮檔案（打包傳送給他人）

{% stepper %}
{% step %}
### 選取檔案

用滑鼠選取所有要打包的檔案或資料夾。
{% endstep %}

{% step %}
### 加入壓縮檔

在選取的檔案上點選滑鼠右鍵 ➔ 選擇 **「加到壓縮檔... (Add to archive...)」**。
{% endstep %}

{% step %}
### 設定參數（可選）

* **壓縮格式：** 預設為 `RAR`（壓縮率較高），若要傳給 Mac 用戶建議改選 `ZIP`（相容性最高）。
* **設定密碼：** 若檔案具隱私性，可點擊「設定密碼」按鈕加密。
{% endstep %}

{% step %}
### 完成

點擊 **「確定」**，同目錄下就會生成一個打包好的壓縮檔。
{% endstep %}
{% endstepper %}

## 4. 常見問題與排障 (FAQ)

<details>

<summary>Q1：為什麼解壓縮時顯示「檔案損毀」或「CRC 錯誤」？</summary>

* **原因：** 通常是下載過程中網路不穩定，導致檔案下載不完整。
* **解法：** 請刪除舊檔，重新下載一次後再解壓；或是確認下載空間是否足夠。

</details>

<details>

<summary>Q2：解壓縮時出現「密碼錯誤」，但我輸入的是正確的？</summary>

* **原因：** 密碼複製時可能不小心夾帶了「空白鍵」，或是輸入法切換到了全形。
* **解法：** 請手動輸入密碼，並注意區分大小寫。

</details>

<details>

<summary>Q3：WinRAR 跳出提示「請購買授權」，還能繼續使用嗎？</summary>

* **原因：** WinRAR 是共享軟體，試用期後會跳出提示。
* **解法：** 可以不用理會，直接關閉提示視窗，核心的解壓縮功能**完全可以免費且無限期正常使用**。

</details>
