## **各種疑難雜症，通用處理方法**&#x20;

* <mark style="color:yellow;">**刪除以下垃圾驅動99%解決問題**</mark>\
  \
  <mark style="color:purple;">**AMD 驅動(除了顯示卡驅動)**</mark> \ <mark style="color:purple;">**INTEL 驅動**</mark> \ <mark style="color:purple;">**NZXT 驅動**</mark> \ <mark style="color:purple;">**海盜船 驅動**</mark> \ <mark style="color:purple;">**羅技/雷蛇/各種不必要驅動**</mark> \ <mark style="color:purple;">**ASUS/MSI/ASROCK/GIGABYTE驅動**</mark>\
  \
  <mark style="color:red;">**除了顯卡驅動，全部都刪除，重開機再試。**</mark> \
  \
  <mark style="color:yellow;">**刪除以下防毒軟體99%解決問題**</mark> \
  \
  <mark style="color:purple;">**CSGO / 5E平台 / 完美平台 / Faceit平台 金山毒霸**</mark> \ <mark style="color:purple;">**360安全衛士 / 其他內陸防毒 Avast / Avira / ESET**</mark> \ <mark style="color:purple;">**NOD32等等 有關Secure / Safe 字樣的程序全刪除**</mark>

<figure><img src="../../../.gitbook/assets/image (399).png" alt=""><figcaption></figcaption></figure>

* 輔助啟動之後，遊戲無法正常啟動 \
  遇到這問題通常代表輔助需要更新，耐心等待更新完成就好。
* 在遊戲中沒有效果\
  試著清理系統暫存檔案，此舉動不影響你電腦的既有檔案(只是清理緩存)。\
  以下檔案下載>解壓縮到桌面之後，右鍵>管理員運行>按任一按鍵退出即可。\
  下載簡單清理執行檔 : [點我下載](https://mega.nz/file/KbgDkLTa#hrPGTdOvknpxaSbyrI9bs6yxwLW13eUHFiDkLOws92k)
