# 常見問題(FAQ)

<details>

<summary><mark style="background-color:red;"><strong>關於輔助安全</strong></mark></summary>

不管輔助穩不穩、防不防檢測，演戲都是必須要的。 \
人工封號是掛逼的天敵，如果今天輔助本身安全性很高，你自己又演的像比較強的一般人，那用很久沒問題。 \
\
每隔一段時間就會有奧客說，魚老闆你內存輔助很爛，我怎麼一用就被封，能退款嗎？ \
可以想一想，一款熱門產品很多人在用，別人用幾個月沒事，你第一天就出事 \
是輔助真的不穩，還是自己開法的問題？ \
\
每個輔助都有推薦參數，也有高危險功能，要開危險功能就不要怕被封號 \
用推薦參數加自己演戲，穩穩使用 \
(可以開obs錄自己玩，然後再播來看，如果自己都覺得太誇張，那就是不對了)

</details>

<details>

<summary><mark style="background-color:yellow;">關於封號問題</mark></summary>

被封號了怎麼辦？\
這應該是很多輔助新手的共同疑問 \
老闆自己有一套被封號後的流程 ( 機器碼沒有被鎖的情況適用 ) \
\
`登出被封帳號 ➝ 關閉所有程式 ➝ 刪除殘留 ➝ 重開網路數據機(主要重製MAC地址) ➝` \
`電腦重開機 ➝ 換隻號修復遊戲後繼續爽`

</details>

<details>

<summary><mark style="background-color:orange;">關於鎖主機板</mark></summary>

現在很多遊戲反作弊都有封號順便封主機板的機制，簡單來說就是封主機板後，換帳號也沒辦法玩，這時候就要解機。

</details>

<details>

<summary><mark style="background-color:green;">關於解機碼差異</mark></summary>

軟解 : 使用後原本的機碼會被偽裝成虛擬機碼，但重開機就會變回原本的機碼 \
硬解 : 使用後原本的機碼會被永久性的改成全新的機碼，重開機不會變回原本的機碼 \
\
不管是哪種解機方式，原本被封的帳號已經不能用了，請換乾淨的帳號做使用。

</details>
