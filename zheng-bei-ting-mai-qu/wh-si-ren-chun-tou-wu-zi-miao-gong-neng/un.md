# WH輔助安裝教學

{% hint style="danger" %}
### 必須關閉<mark style="color:red;">\[Discord內嵌功能]</mark>或<mark style="color:red;">\[Blitz / Tracker等其它內嵌程式]</mark>，

### 否則會導致輔助無效果！
{% endhint %}

<figure><img src="../../.gitbook/assets/image (452).png" alt=""><figcaption></figcaption></figure>

## 第一步：安裝輔助檔案

### 1. 先安裝 / 開啟錄影軟體：[Movavi(點我下載)](https://mega.nz/folder/jr5zTayS#hnWcB_R86W0rCubupnoP9g)

必須用我們提供的版本/否則注入無效\
需要此錄影軟體來注入輔助，輔助會偽裝成此軟體。 \
只須看著下列步驟跑完，就可以成功開啟輔助。

<figure><img src="https://lh7-us.googleusercontent.com/iCs16QW6QsmNRiHuP7t5YMPgGuOxJSmgvBZ7aCEVtdyaCyQ71dU29GZEEeMUuO5_46pw2DEbf4_PcKDgUEu7j4aOJMLvoiSpZ-qrCVpu0uAac7kcjX-UWxi3quCsJNMMwCNiDwMDU4bKI1EpWb8u5u8=s800" alt=""><figcaption></figcaption></figure>

### 2. 安裝完後，win鍵搜尋 "screen" 關鍵字 > 打開Movavai錄製軟體

<figure><img src="../../.gitbook/assets/image (475).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
## 每次開啟輔助前都需開啟Movavi軟體，輔助才可正常運行。
{% endhint %}

### 3. 打叉Movavi小工具 (隱藏以方便遊玩)

通常會出現在桌面的最右側，頂部覆蓋出現，打叉後還會存在於後台，不要退出就可以

<figure><img src="https://lh7-us.googleusercontent.com/Z-gtZMBCmkiXJ_IYvT_NxAqfUwBpgWN5hfxivLEG1em1Xub10DfABep36eGnRFI7u_xfNnpWKGklDNcCUbwgOExZ2exwbMI_fF8nXlz4LKCOa4_-gViY_7bHhJ7AVUeIzrRIwz-lfimGHTkBHDcxtDE=s800" alt=""><figcaption></figcaption></figure>

### 4. WH輔助檔案下載：[輔助載點(點我前往)](https://mega.nz/folder/fLgk1Lja#i8iK--2KWIS5REdh92SZeQ)

<figure><img src="https://lh7-us.googleusercontent.com/9FCQXqPOorpshUl6J3j5KFGq3cTqAsHDjARAYR4GyXm4t_1U4Qk3TXue9lSLPmb3LwVq867s5IQhAAHuy69FpuXvHUG2l4DpS-JUEYyRZc3gY5-KLgGXp58yw9tyK5PwQvSi4TWPXD8zRofV9_39R68=s800" alt=""><figcaption></figcaption></figure>

### 5. 右鍵輔助程式(exe) > 管理員身分執行。&#x20;

<figure><img src="../../.gitbook/assets/image (476).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
### 每次啟動輔助都會自我刪除 (每次使用需要重載)
{% endhint %}

### 6. 耐心等待輔助加載 (等待期間不要按任何按鍵)

<figure><img src="../../.gitbook/assets/image (477).png" alt=""><figcaption></figcaption></figure>

### 等輔助出現 Press any key when game is in main menu

<figure><img src="../../.gitbook/assets/image (478).png" alt=""><figcaption></figcaption></figure>

### 7. 不要關閉上面的黑窗 > 開遊戲設置 \[無邊框/視窗化]  按套用> 回到黑窗(遊戲一樣開著) > 按Enter鍵2\~3次 > 成功注入

<figure><img src="../../.gitbook/assets/image (479).png" alt=""><figcaption></figcaption></figure>
