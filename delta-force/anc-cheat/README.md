## 二、安裝輔助

### 1. 下載輔助

1. 去官網下載輔助檔案 [點我前往](https://cn.undetect.net/download/loader) 。
2. 右鍵管理員身分開啟輔助並且輸入卡密

> 每次開啟輔助，他會下載最新版檔案，並且隨機更改檔案名稱(亂碼)，建議創一個資料夾放輔助檔案，以免找不到。\
> ![](<../../.gitbook/assets/image (199).png>)

<div align="left"><figure><img src="../../.gitbook/assets/Snipaste_2025-05-08_11-57-25 (1).png" alt="" width="410"><figcaption></figcaption></figure></div>

3. 等待輔助加載(0-3分鐘不等)\
   ![](<../../.gitbook/assets/image (530).png>)
4. 選擇遊戲(買什麼卡就選什麼遊戲)
5. 首次使用請先按\[F7按鍵] 並馬上按下下方\[Load按鈕] ，後面開都不用按\[F7按鍵]

> Spoofer=過機碼功能 | <mark style="color:$danger;">機碼本身沒問題不建議開</mark>，這個大機率造成閃退、黑頻、電腦無限重開機等問題

<div align="left"><figure><img src="../../.gitbook/assets/Snipaste_2025-05-08_11-57-45.png" alt="" width="403"><figcaption></figcaption></figure></div>

{% hint style="danger" %}
**建議如果機碼本身沒問題 不用去開Spoofer 此功能不穩定性較高 安全演戲使用的話請不要打勾**
{% endhint %}

{% hint style="danger" %}
建議如果機碼本身沒問題 不用去開Spoofer 此功能不穩定性較高 安全演戲使用的話請不要打勾
{% endhint %}

6.  等待輔助加載 (需要一點時間，跑完之後請等待加載頁面消失)

    <div align="left"><figure><img src="../../.gitbook/assets/image (532).png" alt="" width="563"><figcaption></figcaption></figure></div>

{% hint style="info" %}
如果有開過機碼功能會自動重啟電腦，重啟電腦後請再次打開輔助，做上方2\~5步驟)
{% endhint %}

7. 加載頁面消失後，直接去啟動遊戲
8. 好了，輔助裝好了，開一把去爽吧!
9. 如果程序(副檔名)變成.com，請直接雙擊啟動輔助

{% hint style="success" %}

{% endhint %}

## 三、疑難排解

### 輔助無法啟動

* 輔助官方錯誤除錯方法：[點我前往](https://telegra.ph/ANCIENT-FAQ-CN-07-20)
* 請確保你有把 [通用前置作業四步驟](https://fishboss.gitbook.io/tutorial) 做完
* 查看[疑難排解](https://fishboss.gitbook.io/tutorial/instruction/faq)
* 關閉 安全開機
* **注意這邊此款輔助需要 \[開啟VT] 並 \[關閉Hyper-V]**
* 確保防毒程式已經關閉，這也包括特戰等反作弊程式
* 遊戲必須設置為視窗化或無邊框
* 烽火模式需啟動Disable teamchack才能看到敵人

### 輔助開啟無反應 / 閃退 / 卡死

* 請確保你有把 [通用前置作業四步驟](https://fishboss.gitbook.io/tutorial) 做完
* 請更改系統例外語言為 英文(美國)
* 重新安裝顯卡驅動，安裝好重開機後重新注入輔助
* **注意這邊此款輔助需要 \[開啟VT] 並 \[關閉Hyper-V]**

### 遊戲黑頻 / 輔助黑頻 (解決辦法)

* [關閉GPU硬體加速](../../instruction/faq/ting-yong-gpu-ying-ti-jia-su.md)
* [關閉遊戲模式](../../instruction/faq/ting-yong-gamebar-+-you-xi-mo-shi.md)
