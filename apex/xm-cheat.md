## 二、安裝輔助

### 驅動載點：[點我前往](https://www.leigod.com/download-win.html) (一定要安裝！！)

### 程序載點：[點我前往](https://qqq.lanzouq.com/b0fp7sjqb)

天卡周卡月卡都可以從載點下載（選擇數字最大的即可）

不過月卡也可從卡號派發內容下載（<mark style="color:red;">獨立版本，更加穩定</mark>）

### 首先打開雷神加速器，不需登入，縮小至後台即可（<mark style="color:red;">不要關閉</mark>）

<div align="left"><figure><img src="../.gitbook/assets/image (192).png" alt=""><figcaption></figcaption></figure></div>

### 接著打開輔助壓縮包（.rar）並把<mark style="color:red;">1.ini</mark>和<mark style="color:red;">卡密.txt</mark>拖到桌面

<mark style="color:red;">！！！不要全部解壓縮</mark><mark style="color:$primary;">，</mark>只需要把兩個文件拖到桌面就好

<div align="left"><figure><img src="../.gitbook/assets/image (193).png" alt=""><figcaption></figcaption></figure></div>

### 完成後打開位於桌面的卡密.txt，輸入卡號後Ctrl+s保存

<div align="left"><figure><img src="../.gitbook/assets/image (194).png" alt=""><figcaption></figcaption></figure></div>

如果想調整參數請打開桌面上的1.ini

（遊戲途中也可以修改，不過調整後記得<mark style="color:red;">Ctrl+s保存</mark>，回遊戲後<mark style="color:red;">按F2套用</mark>）

<div align="left"><figure><img src="../.gitbook/assets/image (195).png" alt=""><figcaption></figcaption></figure></div>

### 打開輔助壓縮檔：直接雙擊輔助(.exe程序)

{% hint style="warning" %}
請特別注意

#### 不要解壓縮，直接雙擊打開輔助即可，否則封號!
{% endhint %}

<div align="left"><figure><img src="../.gitbook/assets/image (124).png" alt=""><figcaption></figcaption></figure></div>

### 有配備過機碼功能，但如果不想使用或電腦<mark style="color:red;">已有用硬／軟解</mark>，點選［否］即可

<div align="left"><figure><img src="../.gitbook/assets/image (196).png" alt=""><figcaption></figcaption></figure></div>

### 剩餘時間／啟動成功：點選［確定］接著再點一次［確定］就開啟成功了

！！！請注意遊戲設置必須為<mark style="color:red;">視窗化／無邊框</mark>，否則將沒有效果

<div align="left"><figure><img src="../.gitbook/assets/image (197).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="danger" %}
### 關閉輔助方法

### <mark style="background-color:yellow;">本軟體會持續於背景運作，如需徹底關閉，請 「重新啟動電腦」</mark>

#### 中途「重開遊戲」，請在大廳或遊戲中手動按下 \[HOME鍵] 或 \[F11鍵]

#### 此動作是為了重新對準遊戲地址，確保輔助功能重新生效
{% endhint %}

### 輔助設置

* 透過桌面1.ini進行修改
* 更改設置之後請在該文本內ctrl+s保存
* 回到遊戲，在遊戲內按f2使設定生效

### 基礎快捷鍵

自瞄開關：Ctrl+F7或F6

預判開關：F7

地圖雷達：F9

### 其他提醒

1. <mark style="color:red;">不可開著大地圖按F9</mark>（地圖雷達），否則會導致閃退大廳
2. 黃色熱透人物擁有權限(權限哥)，不要隨便鎖他，可能會導致封號
3. 如果你要玩其他遊戲，請務必重新啟動電腦！否則可能會誤封！

## 三、疑難排解

### 輔助開啟閃退 (沒有反應 / 出現錯誤)

先刪除桌布程序/桌面插件/其他工具，包括WallpaperEngine / Fences4等等

### Win系統降級處理(降到22H2即可)

檢查防毒刪除/封鎖,以<mark style="color:red;">管理員身分運行</mark>輔助。

### 必須使用管理員身分運行輔助

### 檢查前置作業是否確實完成

### 卡密錯誤/卡密不存在

請<mark style="color:red;">確認卡號是否正確</mark>，不能有空格，建議複製貼上
