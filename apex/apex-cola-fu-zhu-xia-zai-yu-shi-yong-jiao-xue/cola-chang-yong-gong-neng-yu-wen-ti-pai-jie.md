# COLA 常用功能與問題排解

這篇整理了 COLA 的幾個實用功能，以及使用時可能遇到的常見問題。

如果你是第一次使用，建議先看 [\[COLA 下載與使用教學\]](./)，完成基本設定後再回來。

## 一、常用功能介紹

### 1. 管理機器碼（Manage seeds）

可以在 Loader 裡管理現有的機器碼設定，或建立新的 Seed。

**操作方式：**

1. 打開 Loader，登入後找到 **Manage seeds**。
2. 如果要移除舊紀錄，點選旁邊的 **Del**。
3. 在 **New seed name** 輸入新的名稱。
4. 點選 **Create** 建立新項目。

{% hint style="warning" %}
**注意**

刪除舊 Seed 前，請先確認是否需要保留原本設定。

畫面中的機器碼開關依目前截圖為預設啟用，但不同版本可能有所差異。變更 Seed 也不代表能解除遊戲停權、保證帳號安全或規避偵測。
{% endhint %}

### 2. 自訂透視顯示

覺得透視顏色不好分辨，或想調整畫面顯示方式？可以從選單內修改。

**操作方式：**

1. 進入遊戲，按 **DEL** 開啟選單。
2. 找到 **透視 → 玩家**。
3. 在右側預覽人物模型上按右鍵。
4. 依照出現的選項調整顏色、顯示樣式等內容。

如果把滑鼠移到模型腳底附近，還能看到更多設定選項。

{% hint style="info" %}
**小提醒**

建議一次只修改一兩個選項，確認畫面效果後再繼續調整，比較容易找到自己喜歡的顯示方式。
{% endhint %}

### 3. 儲存自己的設定檔

花時間調好的功能，不用每次都重新設定。

**操作方式：**

1. 先把選單內的功能調整好。
2. 展開右上角的**設定檔選單**。
3. 在名稱欄位輸入想要的設定檔名稱，例如 `APEX`。
4. 點擊 **＋** 建立設定檔。
5. 建立完成後，確認設定已正確保存。

{% hint style="success" %}
**推薦使用**

確認設定檔可正常載入後，可以依介面選項設為預設設定，方便下次使用。
{% endhint %}

## 二、常見問題與解決方法

遇到問題不用每個方法都試一遍，**找到符合你情況的問題，照著檢查就好。**

<details>

<summary>遊戲打不開、無法正常啟動</summary>

**先確認：** 沒有開啟 COLA 的情況下，遊戲能不能正常執行？

如果連正常開遊戲都會失敗，可以先試：

1. 透過遊戲平台檢查或修復遊戲檔案。
2. 重新啟動電腦，再試一次。
3. 如果仍無法開啟，記錄遊戲顯示的錯誤訊息。
4. 確認問題確實出在遊戲檔案後，再考慮重新安裝。

**怎麼確認？** 在沒有啟動其他輔助程式的情況下，遊戲能正常開啟。

</details>

<details>

<summary>遊戲黑畫面、輔助黑畫面</summary>

這類問題可能與畫面顯示、系統環境或其他程式衝突有關。

**建議先試：**

1. 重新啟動電腦。
2. 確認顯示卡驅動及 Windows 狀態正常。
3. 暫時關閉不必要的錄影、疊加顯示或背景工具，再檢查是否有衝突。
4. 如果仍然黑畫面，保留錯誤畫面並聯絡客服。

這些設定不建議全部直接停用，應依實際問題判斷是否需要調整。

</details>

<details>

<summary>遊戲閃退、輔助閃退或載入失敗</summary>

**先確認是在哪個步驟出錯：**

1. **登入時閃退**：記錄 Loader 有沒有顯示錯誤。
2. **按 Load 後失敗**：確認產品狀態，並查看是否有錯誤提示。
3. **重新開機後出問題**：確認電腦能正常進入 Windows，以及遊戲能否單獨執行。
4. **進遊戲才閃退**：記錄遊戲版本、Windows 版本及當時正在執行的其他程式。

如果系統提示 DirectX 相關錯誤，可以透過 Microsoft 官方方式檢查與修復所需元件。

{% hint style="warning" %}
**不要直接嘗試所有網路上的修復方法。**

像是 Windows 降級、關閉系統安全功能或安裝不明驅動，都不應當成一般排查步驟。如果遇到這類要求，請先聯絡客服確認。
{% endhint %}

</details>

<details>

<summary>卡密錯誤、卡密不存在或無法登入</summary>

請依序確認：

1. 使用的是 **COLA** 對應的卡密。
2. 複製卡密時沒有多出空格。
3. 卡密沒有貼錯、漏字或多字。
4. Loader 能正常連線。

**仍然登入失敗？**

請截圖錯誤訊息並聯絡魚老闆 Discord 客服。

</details>
