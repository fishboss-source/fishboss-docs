# \[APEX] COLA 輔助下載與使用教學

第一次使用 COLA？照著下面的順序操作就可以了。

{% hint style="warning" %}
**⚠️ 開始前，先完成前置作業**

還沒做前置作業的話，請先看這篇：

## 👉 [**\[前置作業教學｜點我查看\]**](../../)

完成後再回來繼續，避免安裝過程發生問題。
{% endhint %}

## 一、下載與登入

{% stepper %}
{% step %}
### 下載 COLA 輔助

👉 [**\[COLA 輔助下載｜主要載點\]**](https://mega.nz/folder/HnJj3AiQ#ATrx49H1tK53xg4UC9swcA)

下載完成後，找到 `loader.zip`，按右鍵選擇 **解壓縮全部**。

解壓縮後，打開資料夾，找到裡面的 `.exe` 主程式。

<div align="left"><figure><img src="../../.gitbook/assets/image (692).png" alt="" width="266"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### 開啟程式並登入

1. 對 `.exe` 主程式按右鍵，選擇 **以系統管理員身分執行**（依目前原始教學）。
2. 開啟程式後，確認目前在 **Key** 分頁。
3. 將購買後取得的卡密貼到 **Product key** 欄位。
4. 點擊 **Sign in** 登入。

<div align="left"><figure><img src="../../.gitbook/assets/image (693).png" alt="" width="339"><figcaption></figcaption></figure></div>

{% hint style="info" %}
**卡密登入失敗？**

請先檢查卡密是否貼錯、有沒有多出空格，以及是否使用正確產品的卡密。不要把完整卡密公開傳到群組。
{% endhint %}
{% endstep %}

{% step %}
### 確認產品狀態並載入

登入成功後，選擇 **Apex Legends**，即可看到產品資訊。

| 畫面項目        | 代表什麼      |
| ----------- | --------- |
| Status      | 目前產品顯示的狀態 |
| Time left   | 卡密剩餘的使用時間 |
| Last update | 最後更新時間    |
| Load        | 載入輔助      |

確認產品狀態後，點擊下方 **Load**。

<div align="left"><figure><img src="../../.gitbook/assets/image (694).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="warning" %}
**重要：點擊 Load 後，依目前原始教學，電腦會自動重新啟動。**

請先儲存其他正在編輯的檔案，避免資料遺失。若出現與教學不同的提示或系統異常，請停止操作並聯絡客服。
{% endhint %}

另外，畫面上顯示的 `Undetected` 或其他狀態，僅代表程式當下提供的資訊，**不能保證帳號不會被偵測或停權**。
{% endstep %}

{% step %}
### 重新開機後，直接開啟遊戲

等電腦重新啟動完成，就可以開啟 **APEX Legends**。

**不需要再重新執行一次 Loader。**

<div align="left"><figure><img src="../../.gitbook/assets/image (695).png" alt="" width="563"><figcaption></figcaption></figure></div>

如果重新開機後遇到遊戲無法開啟或其他異常，可以查看第二篇的 [\[常見問題與解決方法\]](cola-chang-yong-gong-neng-yu-wen-ti-pai-jie.md#er-chang-jian-wen-ti-yu-jie-jue-fang-fa)。
{% endstep %}
{% endstepper %}

## 二、進入遊戲後的基本操作

{% stepper %}
{% step %}
### 按 DEL 叫出輔助選單

進入遊戲後，按鍵盤上的 **DEL（Delete）** 鍵，就能叫出輔助選單。

再按一次可嘗試關閉選單；若實際版本操作不同，請依當前介面為準。
{% endstep %}

{% step %}
### 把介面改成中文

如果看到的是英文介面，可以照下面操作：

1. 點選選單**左下角的帳號區塊**。
2. 找到 **Language／語言**。
3. 選擇 **中文**。

<div align="left"><figure><img src="../../.gitbook/assets/image (696).png" alt=""><figcaption></figcaption></figure></div>

完成後，就能用中文查看各項功能了。
{% endstep %}
{% endstepper %}
