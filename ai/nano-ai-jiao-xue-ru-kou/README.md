# NANO AI 教學入口

## NANO 使用教學｜新手快速開始

歡迎來到魚老闆（FishBoss）NANO 使用教學。本專區依照首次使用的實際順序，帶你完成登入、模型載入、畫面擷取、輸出方式與基本設定。

> **使用前請先閱讀**：CGC NANO 與 CGC TOP 使用不同架構，TOP 序號無法轉換或直接用於 NANO。使用第三方工具可能違反遊戲服務條款，並有帳號停權等風險；本教學不保證軟體在任何遊戲環境均可使用或不被偵測。

### 第一次使用，從這裡開始

1. 下載檔案、檢查環境與授權登入
2. 認識主介面與狀態資訊
3. 選擇遊戲模型並設定畫面擷取
4. 選擇移動輸出方式
5. 建立基本瞄準按鍵與目標設定
6. 啟動並確認運作狀態

遇到問題時，請直接查看 常見問題與故障排查，無須重讀全部教學。

| 項目   | 資訊                                 |
| ---- | ---------------------------------- |
