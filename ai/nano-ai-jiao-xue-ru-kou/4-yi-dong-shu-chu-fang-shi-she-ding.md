# \[4]移動輸出方式設定

## NANO 移動輸出方式設定

### 選輸出裝置點左側選單的 **移動**。

點「後端」下拉選單，可選擇 以makcu為例:

<figure><img src="../../.gitbook/assets/螢幕擷取畫面 2026-11-07 171935.png" alt=""><figcaption></figcaption></figure>

選擇好後端後，點右下角 **套用並儲存**：

<figure><img src="../../.gitbook/assets/螢幕擷取畫面 2026-11-09 190249.png" alt=""><figcaption></figcaption></figure>

目前支援：

| 選項        | 說明                                                          |
| --------- | ----------------------------------------------------------- |
| 系統輸入      | <mark style="color:$danger;">使用 SendInput（不要使用）</mark>      |
| **drv驅動** | <mark style="color:$primary;">單機驅動(不適合長時間使用)</mark>         |
| KmBox Net | <mark style="color:$primary;">(一般推薦有固件匹配問題有機率無法使用)</mark>   |
| CatBox    | CatBox 裝置(推薦)                                               |
| KmBox A   | <mark style="color:$danger;">KmBox A 裝置(不推薦)</mark>         |
| Makcu     | <mark style="color:$success;">Makcu 裝置(非常推薦cp值極高)</mark>    |
| Ferrum    | <mark style="color:$success;">Ferrum 裝置(非常推薦但這款盒子很貴)</mark> |
| Dhzbox    | Dhzbox 裝置(推薦)                                               |

#### 設定好後按下連線

<figure><img src="../../.gitbook/assets/螢幕擷取畫面 2026-11-09 190517.png" alt=""><figcaption></figcaption></figure>

> **補充**：\
> 使用 `drv驅動` 時，建議先停止擷取 → 套用並儲存 → 再重新啟動。\
> 外部硬體裝置需確認韌體與實際相容性。
