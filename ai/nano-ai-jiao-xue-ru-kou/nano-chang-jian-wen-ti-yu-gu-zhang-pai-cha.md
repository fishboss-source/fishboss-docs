# NANO 常見問題與故障排查

## CGC NANO 常見問題與故障排查

本篇依照「症狀 → 可能原因 → 檢查步驟 → 如何確認」整理。尚未取得完整錯誤代碼和實機結果的項目會明確註記待確認。

> **聯絡客服前**：請提供 NANO 版本、Windows 版本、正在使用的遊戲模型名稱、發生階段及**遮蔽卡密／帳號／裝置識別資訊**後的錯誤畫面。不要傳送完整授權序號。

### 無法下載或開啟程式

**症狀：** 下載失敗、找不到主程式或雙擊後無反應。

**可能原因：** 檔案不完整、下載來源錯誤、系統或執行階段不符合要求，實際錯誤原因待確認。

**檢查步驟：**

1. 核對檔案是否來自魚老闆提供的正式來源。
2. 查看 下載與登入教學 中的資料夾截圖，確認主程式位置。
3. 記錄任何系統錯誤視窗及 Windows 版本。
4. 如果系統提示缺少執行階段，透過可信官方來源確認並安裝相應元件。

**如何確認：** 能開啟 NANO 登入視窗。請勿為了排錯而任意關閉防毒或系統安全功能。

### 卡密登入失敗

**症狀：** 登入後無法進入控制中心，或提示序號、裝置、期限相關錯誤。

**可能原因：** 卡密輸入錯誤、使用 TOP 而非 NANO 序號、授權限制、網路或服務狀態；實際錯誤代碼待確認。

**檢查步驟：**

1. 確認登入的是 CGC NANO，並核對卡密輸入。
2. **天卡同一裝置只能啟用一次**；再次購買也不能在同一裝置重複啟用天卡。
3. 不要在錯誤原因未確定前重複購買或啟用其他序號。
4. 保留遮蔽卡密後的錯誤截圖，交由魚老闆客服核對。

**如何確認：** 能正常登入並進入「總覽」畫面。

### 模型無法載入

**症狀：** 選取模型後報錯、程式沒有顯示模型狀態或啟動失敗。

**可能原因：** 模型檔案不符、系列設定不符、格式或 GPU 相容問題；具體原因須查看日誌。

**檢查步驟：**

1. 核對模型是否由正式來源提供，以及是否對應目前遊戲。
2. 依 模型載入教學 重新確認路徑、模型系列及格式。
3. 確認已按 **套用並儲存**。
4. 記錄錯誤文字或執行日誌，勿盲目切換所有模型類型。

**如何確認：** 啟動後日誌顯示成功載入模型，並有正常的執行狀態；確切成功訊息待實測補圖。

### 沒有畫面或沒有辨識結果

**症狀：** 啟動後沒有擷取畫面、FPS 未更新或沒有可辨識目標。

**可能原因：** 畫面擷取方式、來源、解析度、模型或硬體條件不匹配。

**檢查步驟：**

1. 確認程式已成功啟動，而非僅登入。
2. 核對擷取頁的畫面來源、尺寸及模型要求。
3. 返回總覽確認狀態、FPS 與日誌是否顯示異常。
4. 保存相關畫面供客服定位；不要同時更改大量參數。

**如何確認：** 狀態與畫面擷取資訊正常更新；具體驗證方式待取得正式版測試畫面。

### 輸出或外部裝置沒有反應

**症狀：** 介面已選擇後端，但裝置沒有動作或連線失敗。

**可能原因：** 後端選錯、外部裝置未連線、韌體或驅動不相容。

**檢查步驟：**

1. 回到 移動輸出方式教學，核對所選後端是否對應手上的設備。
2. 確認已按 **套用並儲存**，並檢查裝置連線狀態。
3. 記錄設備名稱、韌體版本與錯誤訊息，供客服核對正式相容性。
4. 請勿安裝不明來源的驅動或停用系統保護機制。

**如何確認：** 後端顯示預期連線／執行狀態，且已在適當的測試環境驗證；各設備的實際成功指標待補。

### 程式已啟動但設定不生效

**症狀：** 調整後仍維持舊設定，或畫面顯示「有未儲存變更」。

**可能原因：** 尚未套用儲存、使用了其他按鍵方案或目標類別沒有啟用。

**檢查步驟：**

1. 返回對應頁面，按 **套用並儲存**。
2. 核對已選取需要使用的按鍵方案。
3. 確認所用模型提供的目標類別與目前設定一致。
4. 若仍有問題，保存當前設定畫面，請客服協助確認。

**如何確認：** 未儲存變更提示消失，重新進入設定頁面後仍保留該設定。

### 哪些情況需要聯絡客服？

如出現授權限制、重複啟用、無法辨識的錯誤代碼、官方模型無法使用或設備相容問題，請透過魚老闆正式客服管道回報。客服管道的直接連結：**待補**。

### 待補實測資訊

* 正式下載網址與檔案檢查方式
* 登入失敗、授權過期及裝置限制的錯誤畫面
* 模型載入成功與失敗的日誌示例
* 各遊戲模型的建議尺寸、系列與擷取方式
* 各輸出後端的相容性與成功指標
* F8／F9 快捷鍵的正式版行為
