本篇只說明介面位置與狀態，不需要在此一次調整所有進階參數。

登入後預設進入「總覽」頁面。

### 介面說明

#### 左側選單

| 選單項目 | 功能        |
| ---- | --------- |
| 總覽   | 狀態監控與效能趨勢 |
| 擷取   | 畫面採集與模型載入 |
| 瞄準   | 按鍵方案與瞄準參數 |
| 雜項   | 其他工具功能    |
| 移動   | 輸出裝置選擇    |
| 系統   | 系統相關設定    |

#### 總覽頁面重點

* **線上狀態**：顯示目前是否就緒、執行時間
* **畫面來源 / 推論引擎**：啟動後會顯示即時資料
* **CPU / GPU / 記憶體使用率**
* **效能趨勢圖**：啟動後才會有曲線

#### 左下角狀態列

* 執行狀態指示燈
* 目前 FPS
* 移動方式（<mark style="color:$success;">例如mckcu</mark> / drv驅動）
* 大顆 **啟動** 按鈕

> 所有設定完成後，再回來點「啟動」。尚未啟動時無即時效能資料不一定是故障。
