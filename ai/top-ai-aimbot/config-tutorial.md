自瞄配置1和2，請把他們的自瞄觸發鍵設定一樣，輔助會優先選擇使用配置1

自瞄速度設置: 進遊戲測試，覺得自瞄太慢提高速度，覺得太快或太抖就調低

這個參數沒有絕對，每個人顯卡效能不一樣，參數一定不一樣
{% endhint %}

{% hint style="success" %}
![](<../../.gitbook/assets/image (95).png>)&#x20;

自瞄範圍設置: 不建議超過預設的150，越低越好

進遊戲測試，覺得很容易瞄到好幾個敵人，就調低

這個參數沒有絕對，每個人顯卡效能不一樣，參數一定不一樣
{% endhint %}

{% hint style="success" %}
![](<../../.gitbook/assets/image (569).png>)&#x20;

自瞄位置設置: apex可以拉到胸附近 特戰拉到頭上

這個參數沒有絕對，每個人都一定不一樣
{% endhint %}

{% hint style="success" %}
![](<../../.gitbook/assets/image (96).png>)

死區範圍設置: 建議預設的0就可以

這個數值越大，自瞄後準星在敵人身上能自由移動的範圍就越大

這個參數沒有絕對，每個人都一定不一樣
{% endhint %}

{% hint style="success" %}
![](<../../.gitbook/assets/image (97).png>)

身位預測: 建議預設關就可以了

如果要開，可以只調整跟隨速度，去測一個用起來舒服的

這個參數沒有絕對，每個人顯卡效能不一樣，參數一定不一樣
{% endhint %}

{% hint style="success" %}
![](<../../.gitbook/assets/image (568).png>)

禁用Y移動：建議預設，打開的話自瞄只會左右移動

Y軸限制：建議預設，是小幅度的限制自瞄幫你移動垂直向，拉越低自瞄越不會垂直移動

這個參數沒有絕對，每個人顯卡效能不一樣，參數一定不一樣
{% endhint %}
