# NANO 下載、安裝與授權登入

## NANO 下載、安裝與授權登入

本篇依照初稿 v1.05 畫面說明；正式下載來源、安裝方式與系統權限仍待確認。

> **授權重要提醒**：NANO 天卡同一裝置只能啟用一次，即使再買天卡也不能在同裝置第二次啟用。TOP 卡密無法轉換至 NANO。

### 下載及環境檢查（待確認）

請使用魚老闆提供的正式來源下載程式，確認 Windows 10／11 x64、Vulkan 顯示卡驅動與 Visual C++ x64 執行階段。不要將停用防毒軟體當成一般必要步驟。正式下載網址、解壓縮方式及是否需要管理員權限待實測。

### 1. 資料夾結構

初稿解壓縮後的資料夾如下；其他版本可能不同：

主要內容說明：

| 檔案 / 資料夾         | 說明                                        |
| ---------------- | ----------------------------------------- |
| `Nano.v1.05.exe` | 主程式                                       |
| `kite-compiler`  | 模型編譯工具資料夾                                 |
| `模型`             | 放置模型檔案的資料夾（建議把 `.onnx` / `.cgckite` 都放這裡） |

> **建議**：把常用模型統一放進「模型」資料夾，之後載入時會比較方便。

***

### 2. 登入

雙擊執行 `Nano.v1.05.exe`，會出現登入視窗：

操作步驟：

1. 在「卡密」欄位輸入你的卡密
2. （可選）勾選「記住卡密」
3. （可選）勾選「自動登錄」
4. 點擊 **登錄**

登入成功後會進入 CGC NANO 控制中心，看到「總覽」頁面。

**無法登入？** 請核對卡密是否屬於 NANO，並保留遮蔽完整卡密的錯誤畫面，再參考 常見問題與故障排查。
