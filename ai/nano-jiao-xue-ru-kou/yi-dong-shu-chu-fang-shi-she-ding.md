# 移動輸出方式設定

## CGC NANO 移動輸出方式設定

介面列出的後端選項不代表全部已通過實機相容性驗證。

點左側選單的 **移動**。

### 選擇輸出裝置

點「後端」下拉選單，可選擇：

目前支援：

| 選項        | 說明                  |
| --------- | ------------------- |
| 系統輸入      | 使用 SendInput（最基本）   |
| **drv驅動** | 驅動型後端；安裝前置條件及相容性待確認 |
| KmBox Net | 網路版 KmBox           |
| CatBox    | CatBox 裝置           |
| KmBox A   | KmBox A 裝置          |
| Makcu     | Makcu 裝置            |
| Ferrum    | Ferrum 裝置           |
| Dhzbox    | Dhzbox 裝置           |

***

### 套用設定

選擇好後端後，點右下角 **套用並儲存**：

> **注意**：不要為了使用 drv 任意停用系統安全防護或安裝來源不明的驅動。
>
> 原稿建議使用 drv，但缺少跨設備驗證，不作為所有使用者的統一推薦。
>
> **原稿補充**：\
> 使用 `drv驅動` 時，建議先停止擷取 → 套用並儲存 → 再重新啟動。\
> 外部硬體裝置需確認韌體與實際相容性。
