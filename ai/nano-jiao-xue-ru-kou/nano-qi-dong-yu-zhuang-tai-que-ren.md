# NANO 啟動與狀態確認

## CGC NANO 啟動與狀態確認

本篇聚焦啟動前檢查和如何判斷成功；原稿中的效能與瞄準調整建議未全部經過實測。

### 1. 啟動程式

所有設定完成並「套用並儲存」後，點左下角大顆 **啟動** 按鈕：

啟動後：

* 左下角狀態指示燈會變化
* 執行日誌會顯示模型載入過程
* 總覽頁的效能趨勢開始有資料

***

### 2. 常用快捷鍵（依初稿記錄，待正式版確認）

| 按鍵     | 功能               |
| ------ | ---------------- |
| **F8** | 僅解除滑鼠按鍵鎖定        |
| **F9** | 開始校正（再按一次或取消可停止） |

***

### 3. 建議操作順序（新手）

1. 登入
2. **擷取** → 載入模型 + 選擇正確模型系列 + 套用儲存
3. **移動** → 選擇經確認適用的輸出方式（例如系統輸入；drv 及外部設備依實測確認）+ 套用儲存
4. **瞄準** → 新增按鍵 → 調整類別 X/Y 位置 → 套用儲存
5. 點 **啟動**

***

### 4. 常見問題與技巧

以下僅為初步排查方向；完整症狀、檢查順序及成功判斷請參考 常見問題與故障排查。

#### 模型載入失敗

* 確認模型系列選擇正確（YOLO v11 / v26 等）
* 優先使用 `.cgckite` 格式
* 首次載入 `.onnx` 會自動轉換，需等待

#### 瞄不準 / 飄

* 檢查 X / Y 位置偏移
* 調整「回應」與「預測」數值
* 確認擷取尺寸與模型輸入尺寸一致

#### 外部裝置無反應

* 先用「系統輸入」測試流程是否正常
* 使用 drv 驅動時需先停止再套用儲存
* 確認裝置韌體與驅動相容

#### 效能優化

* FP16 是否適用、是否改善效能，應以實測為準
* 擷取 FPS 可設為 0（不限制）或依需求調整
* 關閉不需要的類別「參與瞄準」

***

### 5. 完成

到這裡你已經完成 CGC-Nano 的基本設定流程。

建議先在安全環境測試參數，再依實際手感微調 X/Y 位置、回應與預測等數值。
