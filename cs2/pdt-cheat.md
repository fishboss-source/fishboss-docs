## 二、安裝輔助

### 1.前往官網註冊帳號([點我前往](https://predator.systems/products/))

最左下方可以切換成中文介面，選擇簡體中文(CN)

<div align="left"><figure><img src="../.gitbook/assets/image (149).png" alt=""><figcaption></figcaption></figure></div>

右上點擊注冊填入帳號/信箱/密碼， 填好之後請 \[打勾同意註冊】點選\[註冊按鈕]

<div align="left"><figure><img src="../.gitbook/assets/image (150).png" alt=""><figcaption></figcaption></figure></div>

接著去你的註冊信箱收信完成認證

<div align="left"><figure><img src="../.gitbook/assets/image (151).png" alt=""><figcaption></figcaption></figure></div>

### 2.前往官網充值和下載([點我前往](https://predator.systems/products/))

右上方進入產品頁面 - 輸入卡號 - 點選綠色勾勾

<div align="left"><figure><img src="../.gitbook/assets/image (152).png" alt=""><figcaption></figcaption></figure></div>

上方點面板 - 下載啟動器輔助

<div align="left"><figure><img src="../.gitbook/assets/image (153).png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../.gitbook/assets/image (154).png" alt=""><figcaption></figcaption></figure></div>

### 3. 啟動輔助並登陸+注入

亂碼程序=輔助文件，請右鍵以管理員身分執行

登入在官網註冊的輔助帳號+密碼

<div align="left"><figure><img src="../.gitbook/assets/image (155).png" alt=""><figcaption></figcaption></figure></div>

點選右下方的Load按鈕，開始注入(<mark style="color:red;">遊戲需先關閉</mark>)

<div align="left"><figure><img src="../.gitbook/assets/image (156).png" alt=""><figcaption></figcaption></figure></div>

等待輔助出現標語:Waiting for the game...

(初次使用可能需要<mark style="color:red;">3\~10分鐘</mark>不等)

<div align="left"><figure><img src="../.gitbook/assets/image (157).png" alt=""><figcaption></figcaption></figure></div>

### 4.啟動遊戲(必須設置為<mark style="color:red;">無邊框/視窗化</mark>)

請依你購買的輔助為主

<div align="left"><figure><img src="../.gitbook/assets/image (158).png" alt=""><figcaption></figcaption></figure></div>

菜單熱鍵:INS鍵(顯示/隱藏菜單)

可參考下方翻譯圖

翻譯圖還沒來

### 5.特別提醒

子彈追蹤需關閉信任模式才能使用

但信任模式如果<mark style="color:red;">勾選比較穩定</mark>，依照個人需求選擇

## 三、疑難排解

### 1.卡號充值/續卡教學

前往官網右上輸入卡號，點選綠勾

<div align="left"><figure><img src="../.gitbook/assets/image (160).png" alt=""><figcaption></figcaption></figure></div>

### 2.卡號解綁/更換電腦方式(ResetHWID)

前往官網，點選面板分頁，再點選硬件重置即可

(<mark style="color:red;">解綁冷卻為7天，天卡/周卡解綁，請慎重考慮</mark>)

<div align="left"><figure><img src="../.gitbook/assets/image (161).png" alt=""><figcaption></figcaption></figure></div>

### 3.Preparing階段卡死不動

請使用VPN連線至國外(可用自己的或下面的[免費VPN](https://1111-releases.cloudflareclient.com/windows/Cloudflare_WARP_Release-x64.msi))

<div align="left"><figure><img src="../.gitbook/assets/image (162).png" alt=""><figcaption></figcaption></figure></div>

免費VPN簡易教學:

下載完成後按Install到完成為止

<div align="left"><figure><img src="../.gitbook/assets/image (163).png" alt=""><figcaption></figcaption></figure></div>

Win鍵搜尋WARP直接啟動

<div align="left"><figure><img src="../.gitbook/assets/image (165).png" alt=""><figcaption></figcaption></figure></div>

工作列右下角找到灰色的雲(圖標)點開 - 下一步 - 接受

<div align="left"><figure><img src="../.gitbook/assets/image (166).png" alt=""><figcaption></figcaption></figure></div>

將功能向右拉開啟動VPN就完成了

<div align="left"><figure><img src="../.gitbook/assets/image (167).png" alt=""><figcaption></figcaption></figure></div>
