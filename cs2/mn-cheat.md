## 一、前置作業

### 請確保你有把 [通用前置作業四步驟](https://fishboss.gitbook.io/tutorial) 做完

### 做完後先重開機，然後繼續往下看

## 二、安裝輔助

### 1.前往官網註冊帳號([點我前往](https://midnight.im/register/))

右上方先切換English顯示語言

<div align="left"><figure><img src="../.gitbook/assets/image (125).png" alt=""><figcaption></figcaption></figure></div>

一樣右上方點選\[Register]開始註冊輔助帳號

Log in=登入   Register = 註冊   English = 語言

<div align="left"><figure><img src="../.gitbook/assets/image (126).png" alt=""><figcaption></figcaption></figure></div>

依序填帳號/信箱/密碼，接著打勾驗證，最後點選\[Register] 註冊

(密碼建議使用大寫英文+小寫英文+任意符號，較容易註冊成功)

<div align="left"><figure><img src="../.gitbook/assets/image (127).png" alt=""><figcaption></figcaption></figure></div>

### 2.前往官網充值+下載([點我前往](https://midnight.im/usercp/))

&#x20;網頁上方點選User CP分頁，選擇\[Activate KEY]

<div align="left"><figure><img src="../.gitbook/assets/image (128).png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../.gitbook/assets/image (129).png" alt=""><figcaption></figcaption></figure></div>

輸入輔助卡號 - 勾驗證 - 點\[Activate]充值卡號

<div align="left"><figure><img src="../.gitbook/assets/image (130).png" alt=""><figcaption></figcaption></figure></div>

接著前往User CP分頁 - 點選Download - 下載輔助文件

<div align="left"><figure><img src="../.gitbook/assets/image (131).png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../.gitbook/assets/image (132).png" alt=""><figcaption></figcaption></figure></div>

### 3. 啟動輔助並登陸+注入

1.亂碼程序=輔助文件，請右鍵以管理員身分執行

(如有跳出任何提示窗口都點選【確定】即可)

<div align="left"><figure><img src="../.gitbook/assets/image (133).png" alt=""><figcaption></figcaption></figure></div>

2.登錄在官網註冊的輔助信箱+密碼

<div align="left"><figure><img src="../.gitbook/assets/image (134).png" alt=""><figcaption></figcaption></figure></div>

3.點選下方的START IT NOW開始注入(<mark style="color:red;">遊戲需先關閉</mark>)

<div align="left"><figure><img src="../.gitbook/assets/image (135).png" alt=""><figcaption></figcaption></figure></div>

4.點選\[START] 開始加載輔助

(如德國端點下載失敗,<mark style="color:red;">可自行切換</mark>其他國家)

<div align="left"><figure><img src="../.gitbook/assets/image (136).png" alt=""><figcaption></figcaption></figure></div>

5.最後耐心等待輔助出現標語:Now,please start CS2...

(初次使用可能<mark style="color:red;">需要3\~10分鐘</mark>不等，請耐心等待)

接著點確定，就可以啟動遊戲了

<div align="left"><figure><img src="../.gitbook/assets/image (138).png" alt=""><figcaption></figcaption></figure></div>

### 4.啟動遊戲(必須<mark style="color:red;">無邊框/視窗化</mark>)

菜單熱鍵:INS鍵(顯示/隱藏菜單)

推薦參數: [綠演參數](https://midnight.im/cloud/config/share?key=7LBiW8oa7pL7KpBo) [暴力參數](https://midnight.im/cloud/config/share?key=a1K1G56PcV7dEQ8Y)

<div align="left"><figure><img src="../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure></div>

## 三、疑難排解

### 1.菜單中文化教學

熱鍵呼叫菜單- 輔助菜單 - 右上點選設定齒輪

到 \[Language選項]更改為Chinese(中文)

<div align="left"><figure><img src="../.gitbook/assets/image (141).png" alt=""><figcaption></figcaption></figure></div>

### 2.換膚器使用教學

前往庫存選項 - 添加槍枝 - 選擇造型 - 點選保存

<div align="left"><figure><img src="../.gitbook/assets/image (142).png" alt=""><figcaption></figcaption></figure></div>

### 3.卡號充值/續卡教學

前往官網點選CP分頁後點\[Activate KEY]，輸入卡號激活([點我前往](https://midnight.im/usercp/))

<div align="left"><figure><img src="../.gitbook/assets/image (143).png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../.gitbook/assets/image (144).png" alt=""><figcaption></figcaption></figure></div>

### 4.卡號解綁/更換電腦方式(ResetHWID)

前往官網點選CP分頁後點\[RESET HWID即可]

<div align="left"><figure><img src="../.gitbook/assets/image (146).png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../.gitbook/assets/image (147).png" alt=""><figcaption></figcaption></figure></div>

### 5.輔助注入階段卡死(載入過慢/無反應)

方法1:

注入輔助時，自行切換其他國家

<div align="left"><figure><img src="../.gitbook/assets/image (148).png" alt=""><figcaption></figcaption></figure></div>

方法2:

請使用VPN連線至國外(可用自己的或下面的[免費VPN](https://1111-releases.cloudflareclient.com/windows/Cloudflare_WARP_Release-x64.msi))

免費VPN簡易教學:

下載完成後按Install到完成為止

<div align="left"><figure><img src="../.gitbook/assets/image (163).png" alt=""><figcaption></figcaption></figure></div>

Win鍵搜尋WARP直接啟動

<div align="left"><figure><img src="../.gitbook/assets/image (165).png" alt=""><figcaption></figcaption></figure></div>

工作列右下角找到灰色的雲(圖標)點開 - 下一步 - 接受

<div align="left"><figure><img src="../.gitbook/assets/image (166).png" alt=""><figcaption></figcaption></figure></div>

將功能向右拉開啟動VPN就完成了
